# 主仕様決定メモ：TR0 / `baseline_m4` と TR1 / `fixed_slope_m4`

## 1. 目的と結論

### 判断対象

投稿論文の第3章・第4章で示す主状態空間モデルを、次のどちらとするかを判断する。

- **TR0 / `baseline_m4`**：local linear trend。水準ノイズ・傾きノイズをともに推定する既存の主分析仕様。
- **TR1 / `fixed_slope_m4`**：傾き状態は保持するが、傾きノイズを0に固定する固定傾き仕様。水準ノイズ、季節成分、イベントダミーはTR0と同じである。

本メモは既存出力の比較に基づく。新規推定、再予測、追加実装は行わない。

### 推奨方針

**投稿論文では TR0 / `baseline_m4` を主仕様とし、TR1 / `fixed_slope_m4` を最重要の頑健性仕様として扱うことを推奨する。**

TR1を主仕様にできないほどの欠点は見当たらない。むしろ、TR1は尤度をほとんど損なわず、AIC/BICはわずかに良く、主要係数・分解・予測もTR0とほぼ同じである。しかし、この優位は「傾きノイズ1パラメータを減らした簡約化」に対応する小さな情報量基準の差であり、残差自己相関や予測性能を明確に改善した証拠ではない。

したがって、既存の `baseline_m4` を中心にしたデータ接続・分解・予測のストーリーを維持し、TR1を「傾きノイズが実質的に不要でも主要結論が変わらないことを示す強い頑健性確認」として示すのが、10ページ以内の投稿論文として最も説明しやすい。

## 3. 比較結果の要約

### 3.1 モデル適合と簡約性

| 観点 | TR0 / `baseline_m4` | TR1 / `fixed_slope_m4` | 判断 |
|---|---:|---:|---|
| 対数尤度 | 584.0694 | 584.0710 | 差は0.0016で実質的に同じ。 |
| AIC | -1124.14 | -1126.14 | TR1が2.00良い。 |
| BIC | -1043.63 | -1049.29 | TR1が5.66良い。 |
| 収束 | True，warnflag 0 | True，warnflag 0 | 両仕様とも収束。 |
| 傾きノイズ | `2.26e-11`，p値0.999 | 0に固定 | TR0で推定された傾きノイズは実質的に0。 |

TR1のAIC/BIC上の優位は、対数尤度の改善ではなく、傾きノイズを推定しないことによるパラメータ数の削減による。傾き分散は境界値0の近傍にあるため、通常のp値だけを「傾きノイズが厳密にゼロである証明」として使うのは避ける。ここでは、TR1が妥当な簡約仕様であることの補助材料として扱う。

### 3.2 主要イベント係数の安定性

| 効果 | TR0：効果率（p値） | TR1：効果率（p値） | 読み方 |
|---|---:|---:|---|
| `hike_dummy` | -2.31% (0.391) | -2.31% (0.391) | ほぼ同一。本文では強い解釈をしない。 |
| `covid_main` | +3.09% (0.102) | +3.07% (0.107) | 符号・大きさは安定するが、主期間の定義を踏まえ慎重に扱う。 |
| `covid_wave1` | +5.25% (0.004) | +5.30% (0.004) | 符号・大きさ・有意性が安定する。 |
| `covid_2021` | +1.63% (0.200) | +1.63% (0.201) | ほぼ同一。本文では補助的に扱う。 |
| `post_stat_change` | -4.43% (0.066) | -4.42% (0.063) | 接続後の統計的水準補正として安定する。需要の因果効果とは読まない。 |

TR0とTR1では、全ての主要係数の符号・大きさ・p値がほぼ重なる。したがって、主仕様をどちらにしても、COVID初期波、COVID主期間、統計接続後の補正を区別するという中心主張は変わらない。

### 3.3 分解図の違い

既存の `fixed_slope_decomposition_*.png` および `trend_rigidity_*.png` では、次が確認されている。

- fitted values と trend component はTR0とTR1でほぼ重なる。
- seasonal component、外生効果、residualsもほぼ同じである。
- TR0/ TR1の差は、図として前面に出すより、重なりを示す頑健性比較として見せるのが適切である。
- 対照的に、TR2の決定的線形トレンドはCOVID期以降の屈曲を吸収できず、イベント成分・季節成分・残差へ負担が移る。

分解図の見た目も、TR1を主仕様へ置き換える強い実質的理由にはならない。一方で、TR1を頑健性図として示すには十分に明瞭な一致がある。

### 3.4 残差診断

| 指標 | TR0 | TR1 | 判断 |
|---|---:|---:|---|
| Ljung--Box p値（lag 12） | `2.19e-07` | `2.19e-07` | 残差自己相関は両方に残る。 |
| Ljung--Box p値（lag 24） | `1.08e-05` | `1.08e-05` | 固定傾き化で改善していない。 |
| 残差標準偏差 | 0.0107 | 0.0107 | 実質的に同じ。 |

TR1は残差診断の問題を解消しない。このため、「TR1の方が統計的に十分優れたモデルである」とは書かない。TR0/TR1を問わず、残差自己相関を推定・解釈上の限界として明記する必要がある。

### 3.5 fixed B の条件付き予測

fixed Bは、2002年4月〜2023年12月で学習し、2024年1月〜2026年2月を評価する既存設定である。予測期間の外生ダミーは既知として与えている。

| モデル | RMSE | MAE | MAPE | MASE |
|---|---:|---:|---:|---:|
| TR0 / `ssm_conditional` | 8112.66 | 6756.34 | 1.7185 | 0.5402 |
| TR1 / `ssm_fixed_slope` | 8135.05 | 6728.93 | 1.7110 | 0.5380 |

TR1はRMSEが22.39だけ大きい一方、MAE・MAPE・MASEはわずかに小さい。予測線もほぼ重なる。どちらが明確に優れるとはいえず、TR1が予測面で大きく悪化しないことを確認する結果である。

### 3.6 COVID one-year の条件付き予測

COVID one-yearは、2002年4月〜2021年2月で学習し、2021年3月〜2023年5月を評価する補助設定である。ここでは `post_stat_change` が学習期間内で定数0のため、SSMへ含まれないことに注意する。

| モデル | RMSE | MAE | MAPE | MASE |
|---|---:|---:|---:|---:|
| TR0 / `ssm_conditional_baseline_m4` | 18236.02 | 14561.14 | 3.6704 | 1.1797 |
| TR1 / `ssm_fixed_slope` | 18244.60 | 14565.32 | 3.6716 | 1.1800 |

TR1は全指標でごくわずかに悪いが、差は実質的に無視できる大きさである。この結果も、固定傾き化が予測性能を明確に改善する証拠ではなく、TR0とTR1がほぼ同等であることを支持する。

## 4. 主仕様別の利点・欠点

### 4.1 TR0 / `baseline_m4` を主仕様にする場合

**利点**

1. 既存の主分析、データ接続、予測評価、研究メモとの連続性を保てる。
2. local linear trendは、長期トレンドの水準と傾きに確率的変化を許す標準的・説明しやすい構造である。
3. 「まず柔軟な基準仕様を置き、傾きノイズがほぼ0なのでTR1で頑健性を確認した」という論理順が自然である。
4. TR1との比較が、主結果が傾きノイズの仮定に依存しないことを示す明快な査読対応になる。
5. 主仕様を置き換えるために、既存の表・図・予測の名称や記述を広範に差し替える必要がない。

**欠点**

1. 傾きノイズが実質的にゼロであるなら、不要なパラメータを含むように見える可能性がある。
2. AIC/BICはTR1よりわずかに劣る。
3. 「トレンドをより硬くしても結果は変わらない」という結果を主仕様ではなく補助結果として説明する必要がある。

### 4.2 TR1 / `fixed_slope_m4` を主仕様にする場合

**利点**

1. TR0とほぼ同じ尤度で、パラメータが少なく、AIC/BICがわずかに良い。
2. TR0の傾きノイズ推定値がほぼ0であり、データに基づく簡約化として説明できる。
3. 主要係数、分解、fixed B・COVID one-year予測がTR0とほぼ同じであるため、中心結論を損なわない。
4. 「トレンドを必要以上に柔軟にしなくてもイベントと統計接続補正を分解できる」という簡潔な方法上のメッセージを作れる。

**欠点**

1. AIC/BICの差は小さく、残差診断・予測を明確に改善していないため、TR1を唯一の最良仕様と主張する根拠は強くない。
2. 傾き分散が境界値に近いことから、通常のp値を主仕様選択の決定打として扱いにくい。
3. 既存の `baseline_m4` を中心に蓄積された図表・説明との整合を取り直す必要がある。
4. 査読者には「なぜ最初から固定傾きとせず、local linearを比較したのか」「水準ノイズをどこまで制約したか」を追加で説明する必要が生じうる。

## 5. 投稿論文としての採用案

### 推奨案：TR0を主仕様、TR1を最重要の頑健性仕様

第3章では、主SSMをlocal linear trendとして定義する。第4章の主分解図・主イベント効果表はTR0で統一する。第5章で、次の順にTR1を示す。

1. TR0で傾きノイズが実質的に0と推定された。
2. 傾きノイズを0固定したTR1は、同等の尤度でAIC/BICがわずかに良い。
3. 主要イベント係数、分解図、残差、fixed BおよびCOVID one-year予測はTR0とほぼ同じである。
4. よって、中心結論は傾きノイズを推定するか否かに大きく依存しない。

この構成なら、TR0の柔軟なモデル構造を基準としつつ、TR1の簡約性を隠さず報告できる。主仕様をTR0とすることは、TR1を劣るモデルと扱う意味ではない。

### TR1を主仕様に切り替える条件

以下の全てを共著者間で優先する場合は、TR1を主仕様として採用してよい。

1. 「傾きノイズを推定しない簡約SSM」を方法上の中心的な新規性として前面に出したい。
2. 第4章の主図・主表をTR1の既存出力へ統一しても、既存の説明・図表との整合を取り直せる。
3. AIC/BICの小差を過大評価せず、TR0と等価な代替仕様であることを本文に明記できる。
4. 第5章ではTR0を頑健性仕様として対称的に報告する紙幅を確保できる。

現時点の研究目的は「統計接続後の構造変化分解」であり、固定傾き化そのものが主目的ではない。したがって、この切替条件は現時点では満たさないと判断する。

## 7. 本文へ反映する記述方針

- 第3章：TR0を主仕様として式と構成要素を示す。TR1は傾きノイズ0の比較仕様として定義する。
- 第4章：TR0の主分解結果を示す。`post_stat_change` は統計接続に伴う水準補正であり、需要の減少効果と記述しない。
- 第5章：TR0/TR1の比較を表と短い本文で示す。AIC/BICの差だけでTR1を最良としない。TR1b以降は感度表に圧縮し、TR2は未収束を明記する。
- 第6章：fixed B・COVID one-yearとも条件付き予測であり、外生ダミーを既知とする設計を表注に記す。TR0/TR1の予測差は「ほぼ同等」とする。
- 第7章：主結論がTR0/TR1の範囲で概ね安定する一方、残差自己相関と水準ノイズ制約への感度が残る、と結ぶ。

## 8. 本文化前の未確認事項

1. `covid_main` の最終的な開始・終了月を主仕様の図表・本文で統一する。
2. TR0主仕様の係数表・分解図が、同一データ版・同一イベント定義の既存ファイルから採られていることを確認する。
3. 第5章に載せる水準ノイズ感度表の列（AIC/BIC、収束、`covid_main`、`post_stat_change`）を確定する。
4. 残差自己相関を、本文の限界として記す方法と、係数の不確実性をどの範囲まで主張するかを決める。
5. fixed BとCOVID one-yearの表注で、conditional forecastと既知外生ダミーの表現を統一する。
6. TR1を主仕様に切り替えないことを共著者間で確認し、以後の図表作成でTR0/TR1を混在させない。
7. 著者所属・会員区分・連絡先、統計出典の最終表記を別途確定する。

## 9. 決定文案

> 本稿では、既存の local linear trend を含む状態空間モデル（TR0）を主仕様として用いる。傾きノイズを0に固定したTR1は、情報量基準、主要イベント係数、分解結果および条件付き予測においてTR0と概ね同等であったため、主結果のトレンド仕様に対する最重要の頑健性確認として報告する。
