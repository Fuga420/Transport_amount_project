# 第2章「使用データとイベント設定」：データ系列・イベント定義表案

## 1. このメモの位置付け

本メモは，投稿論文の第2章で用いるデータ系列，統計接続，目的変数およびイベント変数の定義を固定するための設計案である。主分析は，`TR0 / baseline_m4` を主仕様とする方針（`main_spec_decision_note.md`）に合わせる。ここでいうイベント変数は，特定期間に対応するモデル上の水準差を表すダミーであり，因果効果を直接に識別するものではない。

本メモでは，既存の接続済みデータと既存の推定結果を整理するにとどめる。接続式，原統計表の正式名称・URL・参照日など，既存資料から確定できない事項は「要確認」と明記する。

## 2. 第2章で記述するデータ系列

### 2.1 使用系列の整理

|区分|系列・出典（現時点）|対象範囲・特徴|第2章での記述方針|
|---|---|---|---|
|旧統計|国土交通省「トラック輸送情報」に基づく宅配便取扱個数系列|14社ベースの系列。接続済みデータの開始は2002年4月。旧統計の最終月は要確認。|後続統計とは対象事業者の範囲が異なることを明記する。|
|後続統計|国土交通省「国土交通月例経済」に基づく宅配便取扱個数系列|大手3社ベースの系列。2022年5月から7月には旧統計との重複比較がある。|同一名称の指標であっても，対象事業者が異なるため，単純に同質な連続系列とはみなさない。|
|接続済み分析系列|`data/processed/parcel_volume_connected.csv` の `number_parcels`|2002年4月から2026年2月まで，287か月。|本論文の推定・予測評価で一貫して用いる分析用系列として示す。|

旧統計と後続統計は，いずれも宅配便取扱個数を対象とする一方，集計対象企業が14社から大手3社へ変化している。重複期間（2022年5月から7月）の後続統計は旧統計のおおむね95～96%であり，両系列の水準差が存在することが既存メモで確認されている。このため，接続後の水準差は，需要変化として解釈せず，`post_stat_change` により統計接続に伴う補正としてモデル化する。

### 2.2 接続方法の記述案

本文では，次の程度までにとどめる。

> 旧統計と後続統計は集計対象企業が異なるため，重複期間の比較を踏まえて接続済み系列を作成した。さらに，後続統計への切替後に生じ得る定義・カバレッジに起因する水準差を，需要変化と区別するため，2022年8月以降を1とする統計接続ダミーを状態空間モデルに含めた。

接続済みCSVを用いること，重複月が2022年5月から7月であること，および接続後ダミーの開始が2022年8月であることは確認済みである。一方で，以下は最終稿前に要確認とする。

- 接続済み系列を作成した厳密な数式・処理規則（比率補正，置換月，丸め処理の有無）。
- 旧統計の最終月および後続統計の原系列の開始月。
- 各原統計の正式な表題，表番号，URL，参照日，ならびに論文での引用形式。
- `number_parcels` の原統計における単位・表記（個数か，別の集計単位か）。

## 3. 分析期間と目的変数

### 3.1 分析期間

主分析の接続済み月次系列は，2002年4月から2026年2月までの287か月である。第2章ではこの期間を「利用可能な接続済み系列の分析期間」と記す。個別の予測評価では学習期間・評価期間が異なるため，それらは第6章で別途示し，第2章の表には混在させない。

### 3.2 目的変数

状態空間モデルの目的変数は，接続済み宅配便取扱個数 `number_parcels` の自然対数とする。

\[
y_t = \log(\texttt{number\_parcels}_t).
\]

対数変換により，水準差に対する係数を概ね比率的な変化として読みやすくする。ただし，本文では係数をそのまま需要の増減率や因果効果と断定せず，「対数取扱個数に対する推定上の水準差」と記述する。予測値を個数尺度で示す場合の逆変換の詳細は，第6章で必要な範囲に限って説明する。

## 4. イベント変数の統一定義

主仕様 `baseline_m4` では，以下の5変数を用いる。各変数は該当月を1，それ以外を0とするダミーである。`covid_main`，`covid_wave1`，`covid_2021` は期間が重複する。これは，COVID期全体に対応する持続的な水準差に加え，初期波および2021年の追加的な差を分けて表現するためである。

|変数名|値が1となる期間|主モデルでの役割|第2章での解釈・注意|
|---|---|---|---|
|`hike_dummy`|2017年10月～2019年12月|運賃改定期に対応する水準差を制御する。|個別事業者の実際の運賃や改定効果を直接測定するものではない。期間設定の根拠となる出典は要確認。|
|`covid_main`|2020年3月～2023年5月（M4）|COVID期に対応する主たる持続的な水準差を表す。|COVID-19の因果効果ではなく，当該期間に対応するモデル上の水準差である。終了月は主仕様のM4として採用し，窓の違いは第5章で頑健性を確認する。|
|`covid_wave1`|2020年4月～2020年5月|初期波に対応する短期的な追加水準差を表す。|`covid_main` と重複する。感染拡大，行動制約その他の要因を分離した効果ではない。|
|`covid_2021`|2021年1月～2021年9月|2021年にみられる追加的な水準差を表す。|`covid_main` と重複する。設定理由・期間根拠の出典は要確認。|
|`post_stat_change`|2022年8月以降|後続統計への接続後に残る水準差を補正する。|需要減少を表す変数ではなく，対象事業者の変更を含む統計接続に伴う水準補正である。|

直近の運賃改定に関する追加ダミー（2023年・2024年の段階的設定）は，既存の感度分析では比較済みである。しかし，対数尤度・情報量規準の改善は限定的であり，一部仕様では収束性にも注意を要する。このため，本論文では直近運賃改定の詳細分析を主張の中心に置かず，必要に応じて第5章の補足的な確認にとどめる。

## 5. 因果解釈を避けるための共通注記

第2章の本文または表注に，次の注記を置く。

> 本研究のイベントダミーは，指定期間に対応する時系列上の水準差を表現するための変数である。観測されない需要要因，季節性，事業者別の料金・サービス変更等を網羅的に統制するものではないため，各係数を当該事象の因果効果として解釈しない。

特に，`post_stat_change` は統計系列の接続に伴う差を需要の変化と混同しないための補正項である。この趣旨を，表中の説明と第2章本文の双方で明記する。

## 7. 第2章の記述順序案

1. 宅配便取扱個数を月次で分析すること，接続済み分析期間（2002年4月～2026年2月）を示す。
2. 旧統計（14社）と後続統計（大手3社）の集計対象が異なること，重複期間が存在することを説明する。
3. 接続済み系列を用いること，接続後の差を `post_stat_change` で補正することを述べる。ここでは，この項を需要減少と記述しない。
4. 対数個数を目的変数とすることを示す。
5. 表-1(b)を参照しながら，5個のイベント変数と重複関係を簡潔に説明する。
6. 因果推論を目的とせず，期間に対応する構造的な水準差の分解を目的とする旨を明記する。
