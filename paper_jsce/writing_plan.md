## 1. 論文の中心主張

**後続統計を接続した宅配便取扱個数系列では、需要・社会的イベントに対応する変化と統計接続に伴う水準差を区別する必要がある。状態空間モデルによりトレンド、季節成分、COVID期・運賃改定期のイベント効果、および統計接続後の補正項を同時に扱うことで、その構造を透明に分解できる。主要な分解結果は local linear trend と固定傾き仕様の間で概ね安定し、条件付き予測でもSSMは競争力を示す。**

この主張では、予測精度の首位や特定イベントの因果効果を結論にしない。貢献は、(i) 後続統計接続を明示した長期系列、(ii) 統計接続補正と需要イベントの分離、(iii) トレンド仕様に対する頑健性の確認、(iv) 情報条件を明示した補助的な予測評価、の4点である。

### ストーリーの骨格

1. 旧統計と後続統計は対象企業範囲が異なるため、単純接続では水準差を需要変化と誤認しうる。
2. 接続済み月次系列（既存出力では `n=287`）に、季節性・トレンド・イベント・`post_stat_change` を含むSSMを適用する。
3. COVID初期波、COVID主期間・2021年局面、統計接続後、運賃改定期を別の成分として扱い、解釈の対象を明示する。
4. local linear trend（TR0）と固定傾き（TR1）は、主要係数・分解・予測で概ね同じ結果を与える。一方、決定的線形トレンド（TR2）は未収束かつ適合・残差診断が悪く、過度な硬直化は支持されない。
5. fixed B の条件付き予測でSSMはSARIMAX grid bestに近い精度を示す。ただし、予測期間のイベントダミーを既知として与えた比較であることを明記する。

## 3. 本文に入れる分析

### 3.1 主分析として扱うもの

1. **後続統計の接続とイベント暦**
   - 旧統計（14社ベース）と後続統計（大手3社ベース）の対象範囲の違いを説明する。
   - 重複確認可能な2022年5月〜7月で後続系列が旧系列の約95〜96%水準であったことは、接続補正を導入する背景として簡潔に使う。
   - `post_stat_change` は2022年8月以降の統計接続に伴う水準差を表す補正項として記述する。

2. **SSMによる構造分解**
   - 対数宅配便取扱個数を、トレンド、季節成分、イベント効果、観測誤差に分解する。
   - イベントは `hike_dummy`、`covid_main`、`covid_wave1`、`covid_2021`、`post_stat_change` を明示する。
   - TR0/`baseline_m4` の既存結果では、`covid_main` は約+3.1%、`covid_wave1` は約+5.3%、`post_stat_change` は約-4.4%であり、TR1でもほぼ同じであった。本文では係数、95%信頼区間又はp値、対数係数からの換算値を同じ表に示す。
   - `covid_wave1` は比較的安定した結果として扱える一方、`covid_main` と `post_stat_change` は期間定義・トレンド仮定を踏まえて慎重に解釈する。

3. **トレンド仕様の頑健性**
   - TR0 local linear とTR1 fixed slopeの比較を本文に入れる。両者の対数尤度はほぼ同じ（584.07）で、TR1はパラメータが少ないため AIC/BIC がわずかに良い（AIC: -1126.14 対 -1124.14）。
   - 既存主仕様で傾きノイズがほぼ0（`2.26e-11`、p値0.999）であることを、固定傾き比較の動機として使う。
   - 水準ノイズを50%、25%、10%へ制約した結果は、制約を強めるほど適合度が悪化し、COVID主効果と統計接続補正が大きくなる傾向を示す。これは「トレンドが硬いほどイベント係数が大きい」という一般則ではなく、本系列での感度として記述する。
   - TR2決定的線形トレンドは未収束（warnflag=2）かつAIC/BIC・残差が悪いため、主仕様候補ではなく境界的な参考比較に留める。

4. **固定傾きSSMの予測上の補助確認**
   - fixed B conditionalで、既存SSM（RMSE 8112.66、MASE 0.5402）と固定傾きSSM（RMSE 8135.05、MASE 0.5380）はほぼ同等である。
   - この比較は、固定傾き仕様が予測面で著しく悪化しないことの確認であり、全モデル横断のランキングではない。

5. **fixed B の予測評価**
   - conditionalでは SARIMAX grid best（RMSE 7975.06、MASE 0.5358）とSSM（RMSE 8112.66、MASE 0.5402）が近い。
   - unconditionalでは seasonal naive が最良（RMSE 13622.78、MASE 0.9291）であったことを、別の情報条件における基準として一文又は表注で示す。
   - conditional forecastでは予測期間の外生ダミーを既知としているため、実運用で将来のイベントを無条件に予測した精度ではないことを本文・表注の双方で明記する。

### 3.2 本文では結果を圧縮して扱うもの

- `covid_main` 終了時点の感度分析：主仕様選択の根拠を1段落と小さな表又は係数帯図で示す。各窓の全図・残差図は補足へ回す。
- 運賃改定期：モデルには含めるが、直近値上げの詳細な分解・個別解釈は補足へ回す。需要以外の要因を除外できないため、本文では効果の存在を過度に強調しない。
- 残差診断：TR0/TR1でLjung--Box p値が小さく、残差自己相関は残る。本文では限界として明記し、全ラグの図表は補足へ回す。

## 9. 執筆前に確認すべき未確定事項

### 分析仕様・数値
