## 研究上の判断

- 予測評価は、全モデルを同一条件で競わせる予測コンペではなく、SSM主分析の補助検証として位置づける。
- unconditional forecast と conditional forecast は分けて解釈する。
- conditional forecastでは、test期間の外生ダミーを既知として与えているため、unconditional forecastと同じランキングで単純比較しない。
- Autoformer系は、fixed Bの参考baselineとして扱う。
- `autoformer_lite` は自前のAutoformer-inspired baselineであり、厳密なAutoformer本体ではない。
- `autoformer_neuralforecast_grid_best` は既存ライブラリ版Autoformerの小規模グリッド探索bestであり、Prophetを上回ったがseasonal naiveには届かなかった。
- `autoformer_neuralforecast_exog` は外生変数なしgrid bestより悪化し、SSM/SARIMAX/Prophet regressorsには届かなかった。
- fixed B conditionalでは、SARIMAX grid bestとSSMが強い。
- SSMは主分析モデルとして、予測面でも一定の妥当性があると整理できる。

## 注意点

- NeuralForecast Autoformerはfixed Bのみの実装であり、fixed Aでは未評価である。
- Autoformer系は小標本月次データでは過学習や設定依存のリスクがあるため、主分析モデルではなく参考baselineとして扱う。
- NeuralForecast実行では `ray_stub_used=True` が記録されている。Windows + Python 3.13環境でray依存に制約がある点に注意する。
- Plotly診断では、SARIMA/SARIMAXのgrid best予測CSVがないため、保存済みCSVのあるfixed仕様の予測線を表示している。
- Plotly HTMLは `include_plotlyjs="cdn"` のため、閲覧時にPlotly JSをCDNから読み込む必要がある。
- 今日の研究ノート作成時点では作業ツリーはcleanである。ただし、今後このファイルを追加すると未コミット変更が発生する。
- 不明な点: NeuralForecast Autoformerのより広いハイパーパラメータ探索を行った場合に性能が改善するかは未確認である。
