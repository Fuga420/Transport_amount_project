# 2026-07-02 研究ノート

## 作業概要

ゼミで「COVID初期1年程度を学習に含め、その後を予測する設定も有用ではないか」という助言を受けた。これを踏まえ、既存の fixed A / fixed B の中間的な予測設定として `covid_one_year` split を追加した。

この分析は、予測評価全体を再構成するものではない。SSM主分析の補助検証として、COVID初期の構造変化をある程度学習した後、その後のCOVID期・回復期をどの程度外挿できるかを確認するために実施した。

## 予測設定

今回追加したsplitは以下である。

| 項目 | 内容 |
|---|---|
| split名 | `covid_one_year` |
| train | 2002-04-01 から 2021-02-01 |
| test | 2021-03-01 から 2023-05-01 |
| cutoff | 2021-02-01 |

目的は、COVID初期1年程度を学習した後、その後のCOVID期・回復期をどの程度予測できるかを確認することである。既存の予測設定との関係は以下のように整理できる。

| split | train | test | 位置づけ |
|---|---|---|---|
| fixed A | 2002-04 から 2019-12 | 2020-01 から 2021-12 | COVID前までで学習し、COVID期を予測する設定 |
| covid_one_year | 2002-04 から 2021-02 | 2021-03 から 2023-05 | COVID初期1年程度を学習し、その後を予測する中間設定 |
| fixed B | 2002-04 から 2023-12 | 2024-01 から 2026-02 | 後続統計接続後も含めて学習し、直近期を予測する設定 |

`covid_one_year` は、COVIDをまったく学習しない fixed A と、COVID後までかなり学習している fixed B の間を埋める補助的な予測設定である。

## 比較モデル

今回比較したモデルは3つに限定した。

| model | forecast type | 役割 |
|---|---|---|
| `seasonal_naive` | unconditional | 前年同月を使う単純基準 |
| `ssm_conditional_baseline_m4` | conditional | 既存の `baseline_m4` SSM |
| `ssm_fixed_slope` | conditional | 固定傾きSSM。硬いトレンド仕様の確認 |

`seasonal_naive` は、test内の実績値を使わない。12か月を超える予測では、過去に生成した予測値を再帰的に使うことをNotebook内で確認した。

SSM系は conditional forecast であり、予測期間の外生ダミーを既知として与えている。今回はSSM主分析の補助検証を目的としたため、SARIMAX、Prophet、Autoformerは対象外とした。

## 外生変数の扱い

`baseline_m4` の候補外生変数のうち、実際に使用されたものは以下である。

- `hike_dummy`
- `covid_main`
- `covid_wave1`
- `covid_2021`

除外された外生変数は以下である。

- `post_stat_change`

`post_stat_change` は 2022-08 以降に立つダミーである。一方、今回のtrain期間は 2021-02 までであるため、train内では定数0となる。既存方針に従い、学習期間で定数の外生変数は除外した。

このため、2022-08以降の統計接続後の水準差は、このsplitでは学習できない。これは本分析の重要な解釈上の注意点である。

## 全体評価結果

`output/forecasts/metrics/covid_one_year_forecast_metrics.csv` に基づく全体評価は以下である。

| model | RMSE | MAE | MAPE | MASE |
|---|---:|---:|---:|---:|
| `ssm_conditional_baseline_m4` | 18236.02 | 14561.14 | 3.67 | 1.18 |
| `ssm_fixed_slope` | 18244.60 | 14565.32 | 3.67 | 1.18 |
| `seasonal_naive` | 19347.95 | 14410.30 | 3.61 | 1.17 |

RMSEではSSM系がやや良い。一方で、MAE、MAPE、MASEでは `seasonal_naive` がわずかに良い。したがって、SSMは大きな外れをやや抑える一方、平均的な絶対誤差ではseasonal naiveが強い可能性がある。

`ssm_conditional_baseline_m4` と `ssm_fixed_slope` は、全体評価ではほぼ同等である。

## 期間別評価の示唆

期間別評価では、以下の傾向が見られた。

### 2021-03 から 2021-12

COVID初期1年を学習した直後の2021年内では、SSM系が `seasonal_naive` より良好だった。

| model | RMSE | MAPE | MASE |
|---|---:|---:|---:|
| `ssm_conditional_baseline_m4` | 13483.34 | 2.69 | 0.90 |
| `ssm_fixed_slope` | 13486.77 | 2.69 | 0.90 |
| `seasonal_naive` | 18922.71 | 3.32 | 1.10 |

この期間では、COVID初期の構造変化を学習したSSM系が有効だったと考えられる。

### 2022年以降

2022年では、`seasonal_naive` がSSM系より良い。

| model | RMSE | MAPE | MASE |
|---|---:|---:|---:|
| `seasonal_naive` | 19902.54 | 3.49 | 1.15 |
| `ssm_conditional_baseline_m4` | 20198.95 | 3.76 | 1.26 |
| `ssm_fixed_slope` | 20201.16 | 3.76 | 1.26 |

特に `post_stat_change_period`、すなわち 2022-08 から 2023-05 では、`seasonal_naive` がかなり強い。

| model | RMSE | MAPE | MASE |
|---|---:|---:|---:|
| `seasonal_naive` | 15542.19 | 3.59 | 1.11 |
| `ssm_conditional_baseline_m4` | 22734.52 | 5.09 | 1.58 |
| `ssm_fixed_slope` | 22761.04 | 5.09 | 1.59 |

図 `covid_one_year_forecast_comparison.png` でも、2022-08以降にSSM系がやや高めに出る場面がある。これは、`post_stat_change` がtrain内で識別できず、統計接続後の水準差を学習できないためと解釈できる。

## fixed slope SSMに関する示唆

`ssm_conditional_baseline_m4` と `ssm_fixed_slope` の予測性能はほぼ同等だった。固定傾きSSMでも、COVID one-year予測で大きく悪化しなかった。

これは、これまでの fixed B 予測比較で、既存SSMと固定傾きSSMがほぼ同等だったことと整合的である。「硬いトレンド仕様でも予測性能は大きく悪化しない」という材料にはなる。

ただし、今回の結果から `fixed_slope_m4` が明確に最良であるとは言わない。あくまで、固定傾き仕様が主分析SSMの補助仕様・頑健性確認として有用である、という慎重な位置づけに留める。

## 研究上の解釈

COVID初期1年を学習に含めると、2021年内の予測ではSSM系が有効だった。一方で、2022年以降、とくに統計接続後の期間では `seasonal_naive` が強くなった。

この結果は、COVID初期の構造変化を学習しても、その後の統計接続後の水準差までは事前に識別できないことを示している。`post_stat_change` は今回のtrain期間内で定数0であり、モデルに学習させることができなかったためである。

したがって、この分析は、固定的なCOVID効果や硬いトレンド仕様の有効性と限界を確認する補助検証として有用である。特に、COVID初期後の短期的な外挿ではSSM系が有効な一方、統計接続後の水準差を含む長めの外挿では単純な前年同月基準が強い場面がある、という整理ができる。

## 注意点

- conditional forecastでは、予測期間の外生ダミーを既知として与えている。
- `post_stat_change` はtrain内で識別できないため、今回のSSM予測には含まれていない。
- `post_stat_change` の影響は、統計接続後の水準差として扱っており、因果効果として解釈しない。
- 今回の結果は、総合比較表にはまだ混ぜず、独立した補助分析として扱う。
- fixed slopeが明確に最良という結論にはしない。
