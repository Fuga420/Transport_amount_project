## 予測評価の設計上の判断

予測評価は、SSM主分析の補助検証として位置づける。主目的は、すべてのモデルを単純な精度競争として順位づけることではなく、主分析モデルである状態空間モデルが予測面でも妥当な候補かを確認することである。

現在の整理では、unconditional forecast と conditional forecast を分ける。

- unconditional forecast: 外生変数を使わず、過去の系列だけで予測するベンチマーク。
- conditional forecast: test期間の外生ダミーを既知として与え、構造変化を考慮する予測。

この2つは情報条件が異なるため、同じ表で単純に優劣を決めない。特にSSM、SARIMAX、Prophet regressorsは、`hike_dummy`、`covid_main`、`covid_wave1`、`covid_2021`、`post_stat_change` などの外生ダミーを使うconditional forecastとして解釈する。

deep learning / Autoformer系については、現在mainで確認できる範囲では `autoformer_lite` のみであり、小標本月次データに対する参考baselineとして扱うのが妥当である。

## 主要結果

### fixed A unconditional

`model_comparison_unconditional.csv` と `model_comparison_best_by_split.csv` では、fixed A unconditional の最良モデルは Prophetである。

| model | RMSE | MAPE | MASE |
|---|---:|---:|---:|
| prophet | 27,498.77 | 6.25 | 2.24 |
| sarima_grid_best | 40,578.64 | 9.59 | 3.53 |
| sarima_fixed | 41,548.02 | 9.84 | 3.62 |
| seasonal_naive | 44,753.89 | 10.34 | 3.83 |
| naive | 80,656.77 | 20.09 | 6.98 |

### fixed B unconditional

fixed B unconditional の最良モデルは seasonal naiveである。

| model | RMSE | MAPE | MASE |
|---|---:|---:|---:|
| seasonal_naive | 13,622.78 | 2.91 | 0.93 |
| sarima_grid_best | 14,790.76 | 3.07 | 0.98 |
| sarima_fixed | 16,686.68 | 3.50 | 1.12 |
| prophet | 26,730.00 | 4.83 | 1.59 |
| autoformer_lite | 35,587.39 | 8.54 | 2.59 |
| naive | 107,649.95 | 27.06 | 8.14 |

### fixed B conditional

fixed B conditional の最良モデルは SARIMAX grid bestであり、SSM conditional が僅差で2位である。

| rank | model | RMSE | MAPE | MASE |
|---:|---|---:|---:|---:|
| 1 | sarimax_grid_best | 7,975.06 | 1.71 | 0.54 |
| 2 | ssm_conditional | 8,112.66 | 1.72 | 0.54 |
| 3 | sarimax_fixed | 8,196.97 | 1.76 | 0.55 |
| 4 | prophet_regressors | 17,877.06 | 3.20 | 1.04 |

Prophet regressorsは、fixed Bの外生変数なしProphetより改善している。Prophet without regressors のRMSEは 26,730.00、Prophet regressors のRMSEは 17,877.06 である。ただし、同じconditional forecastの枠組みでは、SSMやSARIMAXには届いていない。

Autoformer-liteはnaiveよりは良いが、seasonal naive、SARIMA、Prophet、SARIMAX、SSMには届いていない。現mainの成果物からは、NeuralForecast版Autoformer grid bestやAutoformer exogの結果は確認できないため、それらについての結論はここでは不明である。

## 研究上の意味

SSMは、同じ外生変数条件のconditional forecastで、Prophet regressorsよりかなり良好である。また、fixed B conditionalではSARIMAX grid bestに僅差で続いている。

この結果は、SSMを主分析モデルとして使うことに一定の予測面での妥当性を与える。特に、単に外生ダミーを入れるだけでなく、トレンド、季節性、イベント効果を明示的に扱う構造が有効である可能性がある。

小標本月次データでは、深層学習系の参考baselineよりも、季節性・外生変数・状態空間構造を明示したモデルの方が安定している可能性がある。ただし、現在mainで確認できる深層学習系成果物は `autoformer_lite` であり、NeuralForecast版Autoformerの結果は未確認である。

## 注意点

- conditional forecastは、test期間の外生ダミーを既知として与えている。したがって、完全な事前予測というより、イベント情報を条件づけた予測として解釈する。
- unconditional forecastとconditional forecastは情報条件が違うため、全モデルを同じ土俵の単純な精度競争として扱わない。
- Plotly診断HTMLは存在するが、notebookやHTMLの現物確認では、SARIMA/SARIMAXのgrid bestではなく固定仕様の系列が表示対象になっている可能性がある。この点は発表時に注記する。
- NeuralForecast版Autoformer、Autoformer grid search、Autoformer exog、Ray依存に関する成果物は、現在main上では確認できない。Windows側の未push作業に含まれていた可能性がある。
- `autoformer_lite` はfixed Bのみで、unconditional baselineである。
- Windows側の元研究ノートは未pushであり、このノートは現在のmainに存在する証跡からの再構成である。
