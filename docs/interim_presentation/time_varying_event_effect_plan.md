# COVID効果の時変性に関する発展分析の実装方針メモ

## 1. 位置づけと基本方針

本メモは，中間発表用の発展分析として，COVID期に対応する水準差が期間内で減衰する可能性を検討するための設計案である。投稿論文の基準モデル，本文，図表および既存出力は変更しない。新しい分析を実装する場合も，既存の推定結果を上書きせず，output/experimental/ または output/time_varying_event/ 以下に独立した出力を保存する。

本分析でいう「時変性」は，係数そのものを毎月ランダムウォークさせるモデルではなく，COVID期の介入効果にあらかじめ制約した減衰形を与えることを指す。これにより，現行の局所線形トレンドとの役割分担を明確にし，発表時に解釈可能な比較を行う。

## 2. 単純なランダムウォーク型時変係数を避ける理由

観測方程式に

\[
y_t=\mu_t+\gamma_t+\beta_{c,t}c_t+\boldsymbol{\beta}^{\mathsf T}\boldsymbol{d}_t+\varepsilon_t,
\qquad
\beta_{c,t+1}=\beta_{c,t}+\eta_{\beta,t}
\]

のようなランダムウォーク型の時変係数を追加すると，次の問題が生じる。

1. **トレンドとの識別が弱い。** 現行モデルにはレベルと傾きを持つ局所線形トレンドが既に含まれるため，ゆっくり変化するCOVID係数がトレンドの屈曲を吸収し得る。
2. **イベント変数との重複が大きい。** covid_main，covid_wave1，covid_2021 は期間が重複しており，さらに係数を時変化させると，どの成分がどの期間差を説明したかが不明確になる。
3. **分散パラメータの解釈が難しい。** 係数ノイズ分散を推定すると，COVID効果の変化と推定誤差，残差自己相関，トレンドノイズの分担が同時に変わる。
4. **月次観測数に対して自由度が過大になる。** 287か月の系列に多くの潜在係数を追加すると，初期状態や平滑化の設定に結果が依存しやすい。
5. **投稿論文の主張と分離しにくい。** 現行稿は固定期間ダミーを「指定期間に対応するモデル上の水準差」として慎重に解釈している。自由な時変係数を追加すると，この限定的な解釈を超えるように読まれる可能性がある。

したがって，まずは係数ノイズ分散を推定しない減衰型介入を採用し，形状の不確実性を固定グリッドで確認する。ランダムウォーク型は，減衰型で識別性と解釈可能性を確認した後の将来課題とする。

## 3. 現行モデルとの対応

### 3.1 現行モデル（比較基準）

現行の比較基準は，接続済み宅配便取扱個数の対数を目的変数とし，局所線形トレンド，12か月周期の季節成分，観測誤差，および次の5変数を含む状態空間モデルである。

- hike_dummy
- covid_main
- covid_wave1
- covid_2021
- post_stat_change

イベント期間，初期状態，ノイズ共分散の構造，推定法は現行モデルから変更しない。比較基準の係数，対数尤度，AIC/BIC，残差診断を保存済み結果から再確認し，新分析の結果と同じデータ・同じ仕様であることを確認する。

### 3.2 COVID減衰型介入モデル

発展分析の第一候補は，covid_main をCOVID期全体の持続的な水準差，covid_decay を開始直後の追加的な水準差として扱うモデルである。

\[
y_t=\mu_t+\gamma_t
 +\beta_h h_t+\beta_c c_t
 +\beta_d z_t(\rho)+\beta_p p_t+\varepsilon_t .
\]

ここで，\(h_t\) は運賃改定期ダミー，\(c_t\) はCOVID期のステップ型ダミー，\(p_t\) は統計接続ダミー，\(z_t(\rho)\) は減衰型介入変数である。トレンドと季節成分は現行モデルと同一とし，\(\rho\) は推定せず固定する。

COVID期の開始月を \(t_0=\) 2020年3月，終了月を \(t_1=\) 2023年5月とすると，月 \(t\) の経過月数を

\[
k_t=\operatorname{monthdiff}(t_0,t)
\]

と定義し，

\[
z_t(\rho)=
\begin{cases}
\rho^{k_t}, & t_0\leq t\leq t_1,\\
0, & \text{otherwise}
\end{cases}
\qquad (0<\rho<1)
\]

とする。したがって，2020年3月の値は1であり，以後は月ごとに \(\rho\) 倍となる。covid_main を同じ期間のステップ型ダミーとして残すことで，\(\beta_c\) は期間全体に共通する持続的な水準差，\(\beta_d\) は開始直後から減衰する追加差として読む。ただし，両変数は相関するため，係数の分離が安定しているかを必ず診断する。

COVID期の終了後も減衰項を延長する定義は，post_stat_change と重なる期間が長くなる。このため第一段階では現行のCOVID期終了月（2023年5月）で \(z_t(\rho)\) を打ち切る。終了後も減衰を継続する仕様は，別の感度分析として明示的に管理し，基準結果に混在させない。

なお，このモデルでは covid_wave1 と covid_2021 を含めない。これは，減衰項が初期の追加差を連続的に表す代わりに，現行モデルの二つの重複ダミーを外す設計であるためである。現行5変数モデルとの単純比較だけでは，減衰形の効果と変数削除の効果を区別できない。したがって，少なくとも次の3仕様を保存する。

1. 現行5変数モデル（完全な比較基準）
2. hike_dummy，covid_main，post_stat_change のみを用いる縮約ステップモデル
3. hike_dummy，covid_main，covid_decay，post_stat_change を用いる減衰型モデル

## 4. \(\rho\) グリッドと解釈

\(\rho\) は次の5点を固定グリッドとして試す。

| \(\rho\) | 直感的な減衰 | 半減期（月，参考） |
|---:|---|---:|
| 0.70 | 急速 | 約1.9 |
| 0.80 | やや急速 | 約3.1 |
| 0.90 | 中程度 | 約6.6 |
| 0.95 | 緩やか | 約13.5 |
| 0.98 | 非常に緩やか | 約34.3 |

半減期は \(\log(0.5)/\log(\rho)\) による参考表示であり，推定された感染期間や因果的な持続期間を意味しない。各 \(\rho\) について同じデータ期間，トレンド，季節成分，初期化および最適化設定を用いる。AIC/BICだけで最適な \(\rho\) を決めず，係数の符号・大きさ，標準誤差，残差自己相関，トレンド形状，post_stat_change の安定性を併記する。

特に \(\rho\) が0.95や0.98の場合，covid_decay はCOVID期ステップと長期間にわたり似た形になる。この場合は，設計行列の相関，条件数，係数の標準誤差を確認し，数値的に収束していても識別が弱い仕様として扱う。必要に応じて，減衰項を平均中心化する仕様を補足的に試すことはできるが，係数の解釈が変わるため，第一段階では未中心化の定義を主とする。

## 5. 現行モデルとの比較指標

### 5.1 適合度と診断

- 対数尤度，AIC，BIC（同じ観測期間・同じ尤度定義の仕様間で比較）
- 残差標準偏差，RMSE（対数尺度）
- Ljung--Box等の残差自己相関診断。ただし，残差自己相関が残る場合は p 値を参考情報として扱う
- 推定の収束状況，境界解，分散パラメータの極端な値
- covid_main，covid_decay，post_stat_change の係数と比率換算値

### 5.2 分解と識別の確認

各 \(\rho\) について，観測値・適合値，トレンド，季節成分，ステップ型COVID成分，減衰型COVID成分，統計接続補正および残差を同じ尺度・同じ軸範囲で図示する。特に，COVID期の上昇をトレンドが吸収していないか，減衰項が post_stat_change を代わりに説明していないかを確認する。

### 5.3 予測評価（補助）

発展分析で予測まで行う場合は，現行の fixed B と同じ学習・評価期間，原系列への逆変換，RMSE・MAE・MAPE・MASEの定義を用いる。SSMは評価期間の外生変数を既知とする条件付き予測であるため，covid_decay の将来値も選択した \(\rho\) と打切り規則から機械的に与える。これを無条件予測の性能として扱わない。

## 6. 感染者数外生変数モデル

### 6.1 変数の定義案

第二の発展分析として，新規陽性者数を月次集計した外生変数を追加する。候補変数は

\[
x_t=\log(1+\text{月次新規陽性者数}_t)
\]

または，月次値を基準期間の平均と標準偏差で標準化した \(x_t^{\mathrm{std}}\) である。人口規模の影響を避ける必要がある場合は，人口10万人当たりの月次新規陽性者数を先に作成する。どの定義を採用するかは，データ出典と欠測・改訂の状況を確認してから決める。

係数は固定係数 \(\beta_x\) とし，\(\beta_{x,t}\) のような完全な時変係数にはしない。観測方程式は例えば

\[
y_t=\mu_t+\gamma_t+\boldsymbol{\beta}^{\mathsf T}\boldsymbol{d}_t
 +\beta_x x_{t-\ell}+\varepsilon_t,\qquad \ell\in\{0,1\}
\]

とする。

### 6.2 ラグの扱い

- **ラグ0**：同月の陽性者数と取扱個数の対応を記述できるが，同時性や同月内の情報利用可能性に注意が必要である。
- **ラグ1**：前月の陽性者数が翌月の取扱個数に対応するという時間順序を置けるため，予測・解釈上は扱いやすい。

第一候補はラグ1とし，ラグ0を感度分析とする。ただし，月初公表値を月次集計する場合など，実際の情報利用時点が確認できれば順序を再検討する。いずれのラグでも，COVID期ダミーと陽性者数は強く相関し得るため，係数を「感染者数の因果効果」と解釈しない。

### 6.3 データ取得・前処理

厚生労働省等の公的な新規陽性者数データを候補とするが，正式な資料名，公開URL，取得日，集計単位，報告日・発症日等の定義，改訂履歴は実装前に確認する。リポジトリ内には現時点で当該系列が保存されていないため，取得元を確定するまでは数値を本文や図に記載しない。

前処理は次の順序とする。

1. 日次データの重複・欠測・改訂の扱いを確認する。
2. 報告日ベースで月次合計を作成し，宅配便系列の月初ラベルへ対応付ける。
3. 2020年3月以前は，分析対象期間の外生変数として0とするか，標準化の対象から外すかを事前に固定する。
4. log1p の場合は変換式を固定する。標準化する場合は，固定Bの評価では学習期間だけから平均・標準偏差を計算し，評価期間の観測値を前処理に使わない。
5. 原系列，変換後系列，月次集計表，取得メタデータを新規実験ディレクトリに保存する。

報告制度の変更や検査体制の変化が含まれる可能性があるため，感染者数外生変数はCOVID期間の社会的状況を完全に測定するものではない。まずは係数の方向と適合・残差の変化を示す補助分析とし，単独の因果推定結果とはしない。

## 9. 投稿論文本文に入れない理由

第一に，減衰形と \(\rho\) は現時点で仮定したグリッドであり，データから一意に選ばれた構造ではない。第二に，covid_main と covid_decay，局所線形トレンド，統計接続ダミーの間に識別上の重なりがある。第三に，陽性者数は出典・報告定義・改訂履歴を確認する必要があり，現行の接続済み宅配便系列と同じ再現性水準にない。第四に，追加仕様を本文へ入れると，固定期間ダミーに基づく現行稿の中心主張が不明瞭になる。

したがって，本分析は中間発表で「COVID期の水準差を持続成分と減衰成分に分けると結論がどの程度変わるか」を示す補助的な発展分析とする。結果が安定し，データ出典・識別・予測情報条件を確認できた場合に限り，将来の改訂稿や補足資料への採用を検討する。

## 10. 実装前に決める事項

- covid_decay を2023年5月で打ち切るか，終了後も継続させるか（第一候補は打切り）
- \(\rho\) の選択をAIC/BICだけで行わず，係数安定性・診断・解釈可能性をどう総合評価するか
- 現行5変数モデル，縮約ステップモデル，減衰型モデルのどれを発表の比較基準とするか
- covid_main と covid_decay の係数相関・条件数が許容範囲か
- 陽性者数の正式な出典，報告日・発症日，改訂値，人口補正の要否
- log1p と標準化の主変換，ラグ0とラグ1の主設定
- 固定Bで将来の covid_decay を0とする根拠（打切り規則）と，既知外生変数としての扱い
- 発表資料に載せる数値の丸め方と，因果解釈を避ける注記
