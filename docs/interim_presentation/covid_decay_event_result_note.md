# COVID減衰型介入モデル：中間発表用結果整理メモ

## 1. 確認範囲

本メモは，feature/covid-decay-event ブランチ上で既に実行済みの実験結果を，追加推定なしで整理したものである。参照したのは，scripts/experimental/run_covid_decay_event.py，output/time_varying_event/metrics/ 以下のCSV，output/time_varying_event/figures/ 以下のPNG，および実行ログである。投稿論文の paper_jsce/main.tex，main.pdf，references.bib は変更していない。

COVID減衰変数は，2020年3月を起点として

\[
z_t(\rho)=\rho^{k_t}
\]

とし，2023年5月で打ち切った。rho は 0.70，0.80，0.90，0.95，0.98 の固定値であり，推定していない。係数は指定期間・指定減衰形に対応するモデル上の水準差であり，COVIDや統計接続の因果効果を直接推定したものではない。

## 2. 実装した仕様

| 仕様 | 外生変数 |
|---|---|
| 現行5変数モデル | hike_dummy，covid_main，covid_wave1，covid_2021，post_stat_change |
| 縮約ステップモデル | hike_dummy，covid_main，post_stat_change |
| COVID減衰型介入モデル | hike_dummy，covid_main，covid_decay，post_stat_change |

全仕様で，接続済み287か月系列，局所線形トレンド，12か月季節成分，拡散初期化および既存の状態空間モデル実装を用いた。減衰型では covid_main と covid_decay を同時に含め，前者をCOVID期間の持続的な水準差，後者を開始直後から減衰する追加的な水準差として整理した。

## 3. rho別の収束状況と主要係数

比率換算値は 100(exp(beta)-1) である。AIC/BIC，係数，残差診断は同じCSVから確認した。

| rho | 収束 / warnflag | covid_main (%) | covid_decay (%) | post_stat_change (%) | corr(main, decay) | 条件数 |
|---:|:---:|---:|---:|---:|---:|---:|
| 0.70 | True / 0 | +3.90 | +0.51 | −4.07 | 0.358 | 5.59 |
| 0.80 | True / 0 | +3.34 | +2.07 | −4.41 | 0.454 | 5.00 |
| 0.90 | True / 0 | +2.51 | +3.74 | −4.23 | 0.660 | 4.60 |
| 0.95 | False / 2 | +1.23 | +5.51 | −4.05 | 0.857 | 5.51 |
| 0.98 | True / 0 | −2.91 | +10.26 | −4.03 | 0.972 | 10.48 |

現行5変数モデルは収束し，covid_main は +3.09%，post_stat_change は −4.43%であった。これは既存の基準結果と整合する。縮約ステップモデルは推定値を取得できたものの，converged=False，warnflag=2 であり，正式な比較基準としては扱わない。

減衰型では rho=0.70，0.80，0.90，0.98 が収束し，rho=0.95 は未収束であった。rho が大きくなるほど，covid_main の係数が小さくなり，covid_decay の係数が大きくなる傾向がある。rho=0.98では covid_main が負方向となり，covid_decay が +10.26%まで膨らむため，成分分担の不安定化が示唆される。

## 4. AIC/BICと残差診断

減衰型の対数尤度は rho=0.70 の 578.71 から rho=0.98 の 580.82 へ上昇し，AICは −1115.42 から −1119.63，BICは −1038.57 から −1042.78へ低下した。この範囲では，AIC/BICだけを見ると大きい rho が有利に見える。しかし，rho=0.95は未収束であり，rho=0.98は設計行列の相関が0.972，条件数が10.48と高い。したがって，AIC/BICの単調な改善をもって最良rhoを決めることはできない。

減衰型の残差標準偏差はおおむね0.0109から0.0110である。Ljung--Box検定のp値は，ラグ12でおよそ5.9×10^-7から2.6×10^-6，ラグ24でおよそ1.3×10^-5から5.4×10^-5の範囲にあり，残差自己相関が残っている。したがって，適合度や係数のp値は参考情報として扱い，減衰型モデルが残差構造を解消したとは説明しない。

## 5. rho=0.90の扱い

rho=0.90は中間発表の代表例として使用可能である。収束し warnflag=0 であり，covid_main は +2.51%，covid_decay は +3.74%，post_stat_change は −4.23%である。covid_main と covid_decay の相関は0.660，設計行列の条件数は4.60であり，rho=0.98より識別上の懸念が小さい。また，代表分解図 components_representative_rho090.png が生成済みである。

ただし，rho=0.90をデータから選ばれた最適値や，COVID効果の真の減衰率と位置づけてはならない。これは，固定グリッドの中で収束性，係数の解釈可能性，識別診断を説明しやすい代表値として用いる位置づけである。

## 6. rho=0.98の扱い

rho=0.98は，識別が弱い例として示すべきである。covid_main と covid_decay の相関が0.972，条件数が10.48であり，二つの項がほぼ同じ長期形状を持つ。標準誤差も covid_main 0.0594，covid_decay 0.0618 と大きく，係数の符号・分担が不安定である。

中間発表では，rho=0.98のAIC/BICが相対的に良いことだけを強調せず，「適合度の改善と引き換えに成分識別が弱くなる例」として示す。主結果や代表図の根拠には用いない。

## 7. 縮約ステップモデル未収束の扱い

縮約ステップモデルは，推定値とAIC/BICが得られていても converged=False，warnflag=2 である。したがって，現行5変数モデルとの比較で「covid_wave1 と covid_2021 を削除した方が良い」と結論づけることはできない。

発表資料では，縮約モデルを「減衰型を導入する際の補助的な縮約仕様」と明記し，数値は参考表示にとどめる。減衰型の解釈は，現行5変数モデルを比較基準としつつ，仕様構成の違いを注記して行う必要がある。

## 9. 解釈上の注意

- covid_main と covid_decay は，固定した期間と減衰形に対応するモデル上の水準差である。
- post_stat_change は後続統計接続に伴う水準補正であり，需要減少を意味しない。
- 減衰型モデルの係数をCOVID-19の因果効果，行動変化の因果効果，または感染者数の影響として解釈しない。
- rhoは推定値ではなく，事前に固定した形状パラメータである。
- AIC/BICは収束性，係数安定性，設計行列の相関・条件数，残差診断と併せて評価する。
- 残差自己相関が残るため，標準誤差とp値は参考情報として扱う。

## 10. 中間発表での結論案

COVID期をステップ型の持続的水準差と減衰型の追加水準差に分ける制約付きモデルを試したところ，rho=0.70から0.90では covid_main と covid_decay の分担が比較的安定し，post_stat_change もおおむね −4%前後であった。一方，rho=0.98では両成分の相関が高まり，係数分担が不安定になった。したがって，rho=0.90を説明用の代表例として示し，rho=0.98を識別の弱さを示す例として併記する。ただし，いずれも因果効果の推定や最適な減衰率の選定ではなく，現行モデルの構造解釈を補助する予備分析である。
